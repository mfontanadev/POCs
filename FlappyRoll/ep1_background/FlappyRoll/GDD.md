# "Flappy Roll GDD"

This document is called GDD because is the Game Design Document, a place where you can find all the researching documentation about the game. 

It serves as a helpful reference for development details, especially if time has passed and you need to recall specific decisions or processes.

The following structure is a generic example of how I organize my projects.

NOTE: this reflects my personal perspective on GDDs and how I utilize them.

## Section Index

This section is the document's table of contents. You can use auto-generated index tables. Example:

* TODO pag 1 

* Links pag 2

* Tools pag 3

## Section TODO

This section lists all tasks currently in **IN PROGRESS** or **PENDING** status. Example:

* **DOING**: create banner for game title.

* **DOING**: bug fixing, investigate why the main screen in not scrolling.

* Add localization.

* Clean code.

## Section Tools

This section lists all tools used in the project. It is good practice to keep offline installers for these programs in case you want to reuse them for another project. Example::

* **Sound editor:** link to the page or name of the sound editor.

* **Graphic editor:** link to the page or name of the graphic editor.

* **Video editor:** link to the page or name of the video editor.

* **Some helper program:** location of the installer.

## Section Researching

This section contains details regarding the origin of documentation used to create the game, pending research, or general notes for the future:

* **Refactor:** add a sound manager in order to simplify the mechanism of playing sounds.

## Section Delivery pipeline

This section covers the delivery process: compilation, deployment, hosting, publishing, and marketing. Example:

* **Generate documentation:** create .md file, collect images for marketing, an so on.

* **Upload to repository:** upload game to repository and expose to public repository all public information.

* **Create marketing resources:** generate videos and images to be shared.

* **Upload public information to social media:** publish marketing resources into social media.
