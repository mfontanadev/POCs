# "Flappy Roll"

This time I based my inspiration in the real Flappy Bird and then added a twist. The idea is that you need to stay between two bands (top and bottom), they represent the flotation bands used in Argentina to contain the dollar. 

As always, this is the top of the iceberg, in this project you will find references to motivation, tribute and a mini framework to make your own games in javascript, I like to call it "my version of SPA, using canvas".

## Building a new version

No steps must be performed, just modify source code and have fun.

<b>Running locally:</b>

To avoid cross-reference browser constraints, when you try to open index.html just from the file system, you can use "http-server" from NPM (take a look at 
<a href="https://www.npmjs.com/package/http-server" target="_blank">NPM http-server</a>, download NPM and http-server package if you don´t have it).

* Step 1: in root dir type: "http-server" and then enter.
* Step 2: open a browser window and type "localhost:8080".
* PLAN B: download "Web Server for Chrome" plugin and set initial folder to "RiseOfLadybug" in your disk.
